# AlgoVista AI – Algorithm Complexity and Data Science Studio

An interactive Python-based platform designed to explore algorithms, analyze time and space complexity, benchmark performance, and perform basic data science operations.

## Overview

AlgoVista AI helps students and developers understand algorithm behavior through practical execution, performance measurements, complexity analysis, and data visualization.

## Features

- **Algorithm Lab:** Execute sorting and searching algorithms.
- **Performance Analyzer:** Benchmark algorithm execution time across different input sizes.
- **Complexity Analyzer:** Compare empirical performance against theoretical complexity models.
- **Space Analyzer:** Explore algorithm memory usage.
- **Data Science Lab:** Upload CSV datasets, inspect data, analyze missing values, and generate visualizations.
- **Interactive Dashboard:** Access project modules through a Streamlit interface.

## Technology Stack

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- psutil

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Loharika1234/AlgoVista-AI.git
```

2. Navigate to the project directory:

```bash
cd AlgoVista-AI
```

3. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run app.py
```
