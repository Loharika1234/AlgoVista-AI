# Version 0.1.0 – Initial Public Release
<badge color="success">Released</badge>
The foundation of AlgoVista AI is here! The first release introduces an interactive environment for algorithm experimentation, performance measurement, complexity prediction, and data exploration.
### Added
- Interactive Merge Sort execution.
- Sorting results and comparison counting.
- Execution-time measurement.
- Peak Python-traced memory allocation tracking.
- Merge Sort benchmarking across multiple input sizes.
- Average and median execution-time analysis.
- Empirical complexity prediction using R²-based model comparison.
- CSV dataset upload and preview.
- Dataset dimensions and missing-value analysis.
- Statistical summaries using Pandas.
- Histogram, scatter plot, department-wise count chart, and correlation heatmap.
- Interactive Streamlit application.

# Versioning Policy
AlgoVista AI follows a structured versioning approach:
- **Major version (1.x.x):** Significant platform milestones or major changes.
- **Minor version (x.1.x):** New features and functionality.
- **Patch version (x.x.1):** Bug fixes and smaller improvements.
Only implemented and verified changes will be listed under released versions. Planned features will remain clearly marked as upcoming until they are available.
